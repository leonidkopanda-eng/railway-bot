# Railway Telegram Bot

## Установка

### Шаг 1: Подготовка на GitHub
1. Клонируй репозиторий или используй его на Railway напрямую
2. Убедись, что все файлы на месте:
   - `main_bot.py`
   - `worker.py`
   - `requirements.txt`
   - `README.md`

### Шаг 2: Создание проекта на Railway
1. Перейди на [Railway.app](https://railway.app)
2. Нажми **"New Project"** → **"Deploy from GitHub repo"**
3. Подключи свой репозиторий `railway-bot`

### Шаг 3: Добавление переменных окружения
В разделе **Variables** (в Railway) добавь:

| Переменная | Значение |
|-----------|----------|
| `API_TOKEN` | Токен твоего бота от [@BotFather](https://t.me/botfather) |

### Шаг 4: Настройка кома��ды запуска
В разделе **Settings** → **Start Command** укажи:
```bash
python main_bot.py
```

### Шаг 5: Деплой
Нажми **Deploy** и дождись запуска. Логи будут доступны в реальном времени.

## Функциональность

### Меню управления бота
- **➕ Добавить аккаунт** — добавить до 5 Telegram аккаунтов
- **▶️ Запустить скрипт** — запустить все добавленные аккаунты
- **⏹ Остановить скрипт** — остановить работу всех аккаунтов

### Что делает каждый аккаунт
1. Подключается через Telethon к Telegram
2. Слушает канал `PaulGifting`
3. Автоматически:
   - Извлекает код из кнопок
   - Отправляет `/start {код}` в бота `PashaGiftsBot`
   - Ловит пароль из сообщений и пересылает его боту

## Импорты и зависимости

**main_bot.py** использует:
- `aiogram` — асинхронный фреймворк для Telegram ботов
- `os` — для получения переменных окружения

**worker.py** использует:
- `telethon` — клиент для работы с Telegram API
- `re` — регулярные выражения для парсинга текста

## Типичные ошибки и решения

### ❌ Bot token is invalid
**Решение:** Проверь, что `API_TOKEN` правильно добавлен в Railway Variables

### ❌ ModuleNotFoundError: No module named 'aiogram'
**Решение:** Railway должен автоматически установить зависимости из `requirements.txt`. Проверь логи деплоя.

### ❌ Бот не отвечает на /start
**Решение:** Убедись, что:
- Бот запущен (проверь статус в Railway)
- Токен действительный
- Бот добавлен в свою беседу (отправь ему /start)
